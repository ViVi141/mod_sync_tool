# TASK军事模拟俱乐部武装突袭重铸者模组同步器

## 功能特点

- 自动检测模组更新
- 支持多节点下载
- 智能负载均衡
- 断点续传
- 下载速度限制（0-200Mbps）
- 自动备份和恢复
- 实时进度显示
- 详细的日志记录

## 使用说明

### 基本操作
1. 选择模组列表
2. 设置本地模组路径
3. 选择下载节点（可选）
4. 设置下载速度限制（可选）
5. 点击"检查模组"查看更新状态
6. 点击"同步模组"开始更新

### 下载速度限制
- 使用滑动条或输入框设置下载速度
- 范围：0-200Mbps
- 0表示不限制下载速度
- 建议根据网络情况设置合适的速度
- 可以随时调整下载速度

### 节点选择
- 支持自动选择最佳节点
- 可以手动选择特定节点
- 显示节点延迟和状态
- 支持节点状态实时更新

### 注意事项
- 首次运行会自动检查更新
- 建议定期检查更新
- 请确保有足够的磁盘空间
- 请确保网络连接稳定
- 下载大文件时建议适当限制速度

## 系统要求
- Windows 10/11
- Python 3.8或更高版本
- 网络连接
- 足够的磁盘空间

## 常见问题
1. 无法访问模组目录
   - 以管理员身份运行程序
   - 检查目录权限设置
   - 选择其他目录

2. 下载速度过慢
   - 检查网络连接
   - 尝试其他下载节点
   - 调整下载速度限制

3. 更新失败
   - 检查网络连接
   - 确保有足够的磁盘空间
   - 查看日志了解详细错误信息

## 开发者指南

### 1. 环境准备
- Python 3.8 或更高版本
- 必要的 Python 包：
  ```bash
  pip install minio py7zr requests semver
  ```

### 2. 配置文件结构
#### 2.1 配置服务器文件
在 `https://example/upload` 下需要准备以下文件：

1. `mod_lists.json` - 模组列表配置
```json
{
    "default": {
        "name": "默认模组列表",
        "file": "mod_info.json",
        "description": "默认的模组列表"
    }
}
```

2. `mod_info.json` - 模组信息文件
```json
{
    "mod_id": {
        "name": "模组名称",
        "version": "版本号",
        "filename": "模组文件名.7z",
        "path": "存储路径"
    }
}
```

3. `minio_config.json` - MinIO 配置
```json
{
    "settings": {
        "bucket": "你的存储桶名称",
        "timeout": 30,
        "retry_count": 3,
        "retry_delay": 1,
        "max_workers": 4
    },
    "weifang": {
        "endpoint": "你的节点地址",
        "port": 9000,
        "access_key": "访问密钥",
        "secret_key": "密钥",
        "secure": false
    }
}
```

4. `version.json` - 版本信息
```json
{
    "version": "2.1.2",
    "min_version": "2.1.2",
    "download_url": "下载地址",
    "changelog": "更新说明"
}
```

### 3. 代码修改
#### 3.1 修改配置服务器地址
在 `mod_utils.py` 中修改 `CONFIG_SERVER` 配置：
```python
CONFIG_SERVER = {
    'base_url': '你的配置服务器地址',
    'endpoints': {
        'mod_lists': '/mod_lists.json',
        'minio_config': '/minio_config.json',
        'version': '/version.json'
    },
    'timeout': 10,
    'retry_count': 3,
    'retry_delay': 1,
    'cache_time': 300
}
```

#### 3.2 修改版本信息
```python
VERSION = "你的版本号"
MIN_VERSION = "最低支持版本"
VERSION_CHECK_URL = "你的版本检查URL"
```

### 4. 部署步骤
1. 准备配置服务器
   - 确保所有配置文件都可以通过 HTTP 访问
   - 建议使用 CDN 加速配置文件访问

2. 准备 MinIO 服务器
   - 创建存储桶
   - 配置访问密钥
   - 确保节点可访问

3. 上传模组文件
   - 将模组打包为 7z 格式
   - 上传到 MinIO 存储桶
   - 确保文件名与 `mod_info.json` 中的配置一致

### 5. 测试流程
1. 测试配置服务器访问
```python
mod_lists = ModUtils.get_mod_lists()
print(mod_lists)
```

2. 测试 MinIO 连接
```python
client = ModUtils.get_minio_client('weifang')
print(client.list_buckets())
```

3. 测试模组下载
```python
ModUtils.download_mod('mod_id', '目标路径')
```
